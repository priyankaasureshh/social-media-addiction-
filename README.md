# Social Media Addiction — Data Analytics Project

##  Project Overview

This project analyzes social media usage and addiction patterns to understand how different age groups interact with social media platforms and identify which platforms are most commonly used.

The project explores platform popularity, age-group usage patterns, addiction levels, and demographic differences to uncover meaningful insights into social media behavior.

Using Python, SQL, Tableau, and Power BI, this project follows an end-to-end data analytics workflow, transforming raw data into meaningful insights through data cleaning, analysis, and interactive visualizations.

##  Project Objectives

- Identify the most-used social media platforms.
- Analyze social media usage across different age groups.
- Identify age groups with higher levels of social media addiction.
- Compare usage patterns across social media platforms.
- Explore relationships between demographic factors and social media behavior.
- Identify trends and patterns within the dataset.
- Develop interactive dashboards using Tableau and Power BI.
- Communicate findings through data-driven visualizations.

## Project Workflow

### 1. Data Collection & Understanding

The dataset was explored to understand its structure, variables, data types, and the different factors related to social media usage and addiction.

### 2. Data Cleaning & Preprocessing

Python was used to prepare the dataset for analysis. The preprocessing stage includes tasks such as:

- Handling missing values.
- Removing duplicate records where necessary.
- Correcting data types.
- Cleaning inconsistent data.
- Preparing the dataset for further analysis and visualization.

The preprocessing code is available in the `data_cleaning` folder.

### 3. Exploratory Data Analysis (EDA)

Exploratory Data Analysis was used to investigate patterns and relationships between age groups, social media usage, platform preferences, and addiction levels.

### 4. SQL Analysis

SQL was used to query and analyze the dataset to investigate questions such as:

- Which social media platform is used the most?
- Which age groups show higher social media usage?
- Which age groups have higher addiction levels in the dataset?
- How does platform usage vary across demographic groups?
- What patterns and trends can be identified?

### 5. Dashboard Development

Tableau and Power BI were used to present the analysis through interactive dashboards, helping users explore platform popularity, age-group distribution, usage patterns, and addiction levels.

##  How to Explore This Project

### Prerequisites

- Python 3 installed.
- Required Python libraries installed.
- A SQL environment compatible with your queries.
- Tableau Desktop or compatible Tableau software to open the workbook.
- Power BI Desktop to open the Power BI report.

### Step 1: Clone the Repository

```bash
git clone https://github.com/priyankaasureshh/social-media-addiction-.git
```

### Step 2: Navigate to the Project Folder

```bash
cd social-media-addiction-
```

### Step 3: Run the Python Preprocessing Script

```bash
python data_cleaning/datapreprocessing.py
```

Ensure the script's dataset path matches the actual location of `Data/data.csv`.

### Step 4: Explore the Dashboards

- Open `Tableau/tableau.twbx` in compatible Tableau software.
- Open `Powerbi/social-media-addiction.pbix` in Power BI Desktop.
- Refer to the screenshots in the `screenshots` folder for quick previews.

**Note:** SQL queries and additional Python analysis files can be added to the repository as the project develops.
